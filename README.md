# IMU-DXL

把 IMU 作为 ID 200 的只读虚拟舵机接入机器人总线。控制器无需专用 IMU 串口协议，
按访问普通舵机的方式即可读取姿态与角速度。

同时兼容：

- 飞特 SCS/STS 协议
- DYNAMIXEL Protocol 2.0

设备只读，不提供力矩、目标位置或速度控制功能。

## 在线调试台

**[打开调试台](https://qinmotech.github.io/IMU-DXL/)**

浏览器通过串口直接连接总线，实时显示三维姿态、三轴角速度与姿态曲线，并统计错帧、超时与重试。
支持飞特 SCS/STS 与 DYNAMIXEL Protocol 2.0 两种协议，可切换总线查询频率。

页面完全在浏览器本地运行，采集内容不会上传。

> 需要桌面版 Chrome 或 Edge（浏览器 Web Serial 要求由用户点击按钮授权串口）。
> 打开页面后先选择总线协议，再点击「连接串口」。
